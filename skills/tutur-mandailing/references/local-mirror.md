# Local Mirror

## Source Mirror

- Language: Bahasa Mandailing. Glottolog name: Batak Mandailing.
- ISO 639-3: `btm`. Glottocode: `bata1291`.
- Classification in Glottolog: Austronesian, Malayo-Polynesian, Sumatran, Batakic, Central-Southern Batak, Southern Batak, Angkola-Mandailing, then Batak Mandailing. Toba is not this node.
- Region for this skill: Mandailing Natal and communities that call their speech Mandailing. Peta Bahasa maps the same name as a Batak dialect south of Danau Toba, in the Sumbar border (Pasaman Barat), Rokan Hulu, and Lawe Sigala Barat in Aceh Tenggara.
- Source confidence: Level 2. Kamus Angkola Mandailing–Indonesia, Balai Bahasa Provinsi Sumatera Utara, edisi kedua, cetakan 2021.
- The dictionary preface says the book documents Angkola Mandailing vocabulary for school use. It is not a Toba dictionary.
- Dialect labels inside entries: Akl = Angkola, Mdl = Mandailing. This skill prefers Mdl or unlabeled shared examples.
- Source links are in `sources.md`. This file does not copy the dictionary.

## Local Usability

Use this file offline. A chat may open with the santabi line and then switch to Indonesian. Do not invent a Mandailing paragraph around one noun. Mandailing and Angkola share a dictionary, so a word is not Mandailing just because it sits in that book. Read the label.

Batak Toba has its own skill and its own greeting habit. A line that "sounds Batak" can be Toba, Angkola, Mandailing, or another Batak language. Ask which one.

## Vocabulary And Semantics

Verified items only. Glosses follow the 2021 Balai Bahasa dictionary examples.

- santabi: n tabik; salam (hormat). Example: "santabi di hamu sude", glossed "salam hormat untuk kalian semua". Related: marsantabi, bersitabik; memberi salam (hormat).
- mauliate: n terima kasih. The entry gives the gloss and the pronunciation note [mawliyate]. It does not give a full thanks sentence in the stretch used here.
- ale: pron ayo. Example: "ale, eta kehe", glossed "ayo, kita pergi".
- anggi manyapu alaman: "adik menyapu halaman". anggi is the younger sibling in that sentence. alaman is halaman. The sentence is an unlabeled dictionary example, so it is shared Angkola-Mandailing, not an Akl-only label.
- abis: marked Mdl. One sense is sesudah; setelah. Example: "abis mangan, hita marangkat tu saba", glossed "setelah makan, kita berangkat ke sawah".
- alak: marked Mdl, n orang. Example frame: "bahat do ma alak di tano lapang", glossed "banyak orang di tanah lapang".
- alale: marked Mdl, seru. Example: "alale, na jegesma ho", glossed "aduhai, yang cantiknya kau".
- horas: a selamat. Example: "sai horas hita ibaen Tuhan", glossed "kita tetap selamat dibuat Tuhan". Use this only as that wish. Do not recast horas as the Toba hello.
- madung: appears in examples as sudah, for example "madung abok hepengku", "uangku sudah hilang". Do not build new madung-sentences beyond quoted examples.
- jolo: appears inside examples as dulu, for example instructions like "ambil dulu". Quote it only inside a printed example.

Do not add markobar formulas, horja speeches, or kinship titles that the kamus does not gloss in the line being used.

## Generation Rules

1. Write the meaning in plain Indonesian first.
2. Add only Mandailing pieces listed above or supplied by the user with a source.
3. If a full sentence is not in the dictionary example, keep it in Indonesian and label the message mixed.
4. Say when a line is shared Angkola-Mandailing and when it is marked Mdl.
5. Do not paste an Akl entry into a Mandailing message.
6. Do not borrow Toba greeting formulas.
7. For public or professional text, keep time, place, price, and policy in Indonesian.
