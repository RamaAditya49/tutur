# Usage Patterns

## Ordinary Output

A usable Karo-aware message is short. Open with `mejuah-juah` when a greeting is actually wanted, put the request in Indonesian, and add `bujur` only if thanks belongs there. If the user asked for a full translation, say which pieces are attested and leave the rest in Indonesian.

## Sample Tasks

- Greet a cousin in Kabanjahe and say you will send the photo later.
- Close a group chat note with thanks, using `bujur`, not mauliate.
- Tell a neighbor the meeting is still Saturday morning. Keep the hour in Indonesian.
- Review a text that opens with Horas and calls itself Bahasa Karo.
- Refuse a request for a merga speech or a ritual formula.

## Review Checklist

- Is every Karo word on the list in `local-mirror.md`, or in a sample the user supplied?
- Did the output use Horas, Mauliate, Amang, or Tulang?
- Did the output use Pakpak `njuah-njuah` or Simalungun wording?
- Did the output rebuild a sentence from the broken OCR?
- Were `ula`, `ola`, and `ulang` left in the phrase where they were printed?
- Is mixed text labeled mixed?
- Are names, dates, prices, and instructions unchanged?
- Is adat or merga language absent unless the user pasted it?

## Output Patterns

- Direct request: message first, source note second.
- Review request: name the Toba words, then a shorter rewrite.
- Public request: Indonesian carries the instruction. Karo stays the greeting or the thanks.
