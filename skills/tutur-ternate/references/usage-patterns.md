# Usage Patterns

## Ordinary Output

Lead with one Bahasa Ternate clause that matches the relationship, then the practical point in Indonesian. Say when `ngana` would be the wrong you.

## Sample Tasks

- Tell a peer you are heading home, using `Ngom mi-kudiho toma fala`, with the street in Indonesian.
- Say you do not know yet, using `fangare ware ua`, if the speaker is male in the Watuseke frame.
- Review a sentence that is actually Melayu Ternate.
- Explain `ngori` versus `fangare` without writing a new sentence.
- Refuse a Tidore request and a request for sultanate speech.
- Keep a work roster in Indonesian.

## Register And Semantics

- The prefix agrees with the free pronoun. `ngori` goes with `to-`, `ngana` with `no-`, `ngom` with `mi-`.
- `ngana` is not a neutral kamu. Watuseke limits it to a younger or lower addressee.
- `fangare` and `fajaru` encode the speaker's gender in the polite first person. Do not swap them.
- Melayu Ternate can also use `ngana`. Malay negation and word order show which language it is.
- Code-mixing means an attested clause plus Indonesian, not a hybrid verb.

## Review Checklist

- Is the request Bahasa Ternate rather than Melayu Ternate or Tidore?
- Does each Ternate clause appear in `examples.md`?
- Does the prefix match the pronoun in that same clause?
- Is `ngana` used only where the source uses it, with the rank note?
- Are new facts still in Indonesian?
- Is any court or ritual line absent unless the user supplied it?

## Output Patterns

- Direct request: clause first, then Indonesian.
- Review request: name the Malay features, then one fitting Ternate clause if one exists.
- Unknown rank: Indonesian body, plus the pronoun names, without a new Ternate sentence.
