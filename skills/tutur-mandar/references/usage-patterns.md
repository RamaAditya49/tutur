# Usage Patterns

## Ordinary Output

Text a cousin. Lead with the dictionary sentence that already means the thing, then the practical detail in Indonesian. If no example fits, skip the Mandar sentence instead of coining one.

## Sample Tasks

- Say you want to eat, or tell someone to go home.
- Tell someone to come tomorrow.
- Pass on that there is good news, with the news itself in Indonesian.
- Review a message that opens with Bugis `tabe'` and `iye`.
- Separate a Balanipa request from a Banggae or Pamboang request.

## Review Checklist

- Is every Mandar string a printed 2025 dictionary example, or a user sample?
- Is the glottal written `q`?
- Is `iye` absent?
- Is apostrophe `tabe'` absent?
- Is `itaq` used only where the respectful gloss fits?
- Are Balanipa, Banggae, and Pamboang not treated as identical?
- Is mixed text labeled mixed?
- Are money, time, and place unchanged?
- Is `kalindaqdaq` not newly composed?

## Output Patterns

- Direct request: message, then a one-line source note if the Mandar part is easy to overread.
- Review request: name the Bugis or Makassar leakage, then rewrite.
- Public request: one Mandar example at most, instruction in Indonesian.
