# Usage Patterns

## Ordinary Output

A usable Komering-aware message is short. Put one attested dictionary sentence up front when it matches the situation, then say the practical part in Indonesian. If nothing in the phrase list fits, stay in Indonesian and say so.

## Sample Tasks

- Tell a cousin you are not coming because of rain, using the printed `amon` sentence.
- Ask why someone did not come last night, using the printed `ngapi` sentence.
- Let someone pass seated elders with the `tabik` example, then Indonesian for the rest.
- Write a kampung reminder. Keep the day and the place in Indonesian.
- Review a text that calls itself Komering but opens with Lampung `tabik pun`.

## Review Checklist

- Is every Komering word inside a sentence printed in this skill, or in a sample the user supplied?
- Did the output call `tabik` a general greeting?
- Did the output recombine words into a sentence the dictionary does not contain?
- Is mixed text labeled mixed?
- Are Lampung `tabik pun`, Api, and Nyo absent?
- Did the output assign Pulau Negara or Aji without a source mark?
- Are names, dates, prices, and instructions unchanged?
- Is adat language absent unless the user pasted it?

## Output Patterns

- Direct request: message first, source note second.
- Review request: name the unsupported words, then a shorter rewrite.
- Public request: Indonesian carries the instruction. Komering stays one labeled sentence.
