# Usage Patterns

## Ordinary Output

For a cousin in Kota Gorontalo or a guest note, return the message first. Ask kabar with `Wolo habali?` or greet the time of day with the matching `Paladu` line. Put plans, prices, and addresses in Indonesian. Mark mixed text as mixed.

## Sample Tasks

- Reply to "apa kabar" with `Wolo habali?` and an Indonesian answer.
- Greet a guest in the morning with `Paladu u dumodupo`.
- Thank someone with `Odu'olo` at the end of an Indonesian note.
- Review a text that is Melayu Manado with one Gorontalo word.
- Write a neighborhood reminder for a mixed-age group using `Woloolo habali olanto?` only if the whole group is being addressed politely. Otherwise use a `Paladu` line and Indonesian.
- Stop an adat or wedding-speech request and ask for a local sample.

## Register And Semantics

- `olanto` lines in the conversation book are the polite parallels (Anda). Use them when the book pairs them, not as a suffix on random words.
- `wau` is aku and `yio` is engkau in Pateda 1977. Do not invent the rest of the pronoun set from those two.
- `Temei` and `Tilei` need the nephew's name from the user. Do not coin one.
- Suwawa, Atinggola, Kota, and Bolango are not spelled as one dialect.
- Manado Malay particles are a different language even when the topic is Gorontalo.

## Review Checklist

- Is the greeting one of the conversation-book lines, including its printed spelling?
- Did `Odu'olo` stay a thanks phrase, not a new verb frame?
- Is any `sto`, `kong`, or `dang` left unmarked as Manado Malay?
- Are `Temei` and `Tilei` tied to a name the user gave, with the support note?
- Are facts still in Indonesian?
- Is mixed text labeled mixed?
- Did the answer avoid a full unattested Gorontalo paragraph?

## Output Patterns

- Direct request: message first.
- Review request: point at Manado Malay or invented Gorontalo, then rewrite with one attested line.
- Public text: `Paladu` plus Indonesian details plus `Odu'olo` if thanks is actually owed.
