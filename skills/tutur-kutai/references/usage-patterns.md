# Usage Patterns

## Ordinary Output

Return the message first. A Kutai sentence from the kamus stands only when the Indonesian gloss is what the user needs. The hour, the place, and the money follow in Indonesian. Say mixed when both languages appear.

Cousin chat can open with `hambat-hambat nyawa blm mendi, nya dah datang berayak` when someone really did show up early. It is not a greeting stamp for every morning.

## Sample Tasks

- Chat: one dictionary sentence, then Indonesian for the plan.
- Public reminder: Indonesian for the schedule. Do not turn the megang sentence into a general invitation.
- Admin: deadlines stay Indonesian. There is no attested Kutai form-letter line in this skill.
- Adat or Ramadan eve: quote the megang sentence only for that occasion, and do not add a new sujud formula.
- Review: flag Banjar, Paser, and unlabeled Kota Bangun claims.

## Review Checklist

- Is the variety named, and is Kota Bangun kept off the Tenggarong code `vkt`?
- Does every Kutai sentence match a dictionary example, including the gloss?
- Is `nya` still third person?
- Is Banjar Samarinda left as its own Peta Bahasa dialect?
- Are dates and places still Indonesian?
- Is mixed text labeled mixed?
- Did anyone apply a-to-e to a word the preface did not list?
