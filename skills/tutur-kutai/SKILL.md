# Tutur Kutai

## Overview

Use this skill for Bahasa Kutai as documented by Kamus Bahasa Kutai—Bahasa Indonesia, Kantor Bahasa Provinsi Kalimantan Timur (2013, revised 2021). The 2013 preface says everyday use is concentrated in Kota Tenggarong, Kutai Kartanegara, and it cites the 1974 government split: dialek Kutai Tenggarong, dialek Kutai Kota Bangun, and dialek Kutai Muara Ancalong. Those are not one wording.

Glottolog splits them further: Tenggarong Kutai Malay, glottocode `teng1267`, ISO 639-3 `vkt`; Kota Bangun Kutai Malay, glottocode `kota1275`, ISO 639-3 `mqg`. Peta Bahasa does not file Kutai as Banjar. Under Bahasa Melayu Kalimantan Timur it lists dialek Kutai Kota Bangun, dialek Kutai Muara Lesan, dialek Kutai Muyup Ulu, and, separately, dialek Banjar Samarinda. Do not collapse any of those into Banjar, and do not answer a Kota Bangun request with an unlabeled Tenggarong line.

## Search And Discovery

Relevant searches: Bahasa Kutai, kamus Bahasa Kutai, contoh Bahasa Kutai, belajar Bahasa Kutai, terjemahan Indonesia Kutai, translate Bahasa Kutai, Kutai Tenggarong, Kutai Kota Bangun, Muara Ancalong, Melayu Kutai, AI skill Bahasa Kutai.

Use this skill for source-aware Kutai generation and review. It is not a certified translator. Kota Bangun, Muara Ancalong, Muara Lesan, Muyub Ulu, pantun, public, legal, or official text stays with a speaker of the named variety when the line is not in the local sources.

## Human Voice

Nyawa untuk aku, awak untuk kamu, etam untuk kita, nya untuk dia. Mandi jadi mendi. Pagi-pagi sekali orang bilang hambat-hambat, seperti "hambat-hambat nyawa blm mendi, nya dah datang berayak". Kalimatnya lisan dan sering lanjut ke Indonesia. Ini Kutai yang kamus Kantor Bahasa rekam dengan pemakaian harian terpusat di Tenggarong, bukan Kota Bangun dan bukan Banjar Samarinda. Pantun dan naskah Jawi zaman kesultanan tidak dipakai untuk mengingatkan tetangga.

## Workflow

1. Identify the task.
   - Translation needs a printed Kutai sample of the named variety.
   - Style requests keep the Indonesian meaning and add only attested Kutai sentences.
   - If the user says Kutai without a variety, say the lines on hand are the Tenggarong-centered dictionary, not Kota Bangun.

2. Check source confidence.
   - Read `references/sources.md` first.
   - Example sentences come from the 2021 revision. Dialect names and the a-to-e pairs come from the 2013 preface.
   - Do not apply "a menjadi e" to a new Indonesian word. The preface only lists mandi/mendi, jalan/jelan, darah/derah, balian/belian.

3. Compose with source discipline.
   - Keep names, places, titles, dates, and facts unchanged.
   - Use verified Kutai sentences only.
   - If the sentence is not attested, write Indonesian and label the result mixed.

4. Final pass.
   - Name Tenggarong when a dictionary line is used.
   - Do not claim native-speaker or official authority.
   - Do not answer in Banjar, Paser, or Berau Malay.

## Output Style

- For a direct request, give the message first.
- For a review, name the risk, then give a safer rewrite.
- For public, adat, legal, school, or government text, ask for a speaker of the named Kutai variety.
- Label mixed Kutai-Indonesian text as mixed.
