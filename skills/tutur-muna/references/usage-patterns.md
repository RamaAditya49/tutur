# Usage Patterns

## Ordinary Output

Text like someone on the road in Raha. Ask where the other person is going, or say you are going to Raha tomorrow, using the grammar line. Put the hour, the reason, and the meeting point in Indonesian.

## Sample Tasks

- Greet a neighbor you pass before the market.
- Send a noon note to a cousin.
- Say you are learning `wamba Wuna`, with the class schedule in Indonesian.
- Review a caption that uses Wolio or Tolaki words under a Muna label.
- Refuse an adat composition and ask for the village text.

## Review Checklist

- Is every Muna line taken from the grammar list, or from the user's sample?
- Are brackets explained as infix marks rather than deleted?
- Did the output swap `ne` and `we`?
- Is the dialect named when the place is not Katobu or Raha?
- Are Wolio and Tolaki forms absent?
- Is mixed text labeled mixed?
- Are names, times, and places unchanged?
- Is ritual language absent unless the user pasted it?

## Output Patterns

- Direct request: the message, then a short note if brackets appear.
- Review request: the wrong language or the invented verb, then a rewrite.
- Public request: one greeting, instruction in Indonesian, dialect labeled.
