# Usage Patterns

## Ordinary Output

Give the spoken message first. If the whole line is in the 2025 dictionary, give that line. If only the opener is attested, continue in Indonesian and mark the message mixed.

## Sample Tasks

- Text a cousin with `Ale mo pi mana` and the meeting place in Indonesian.
- Thank someone for pushing a car, using the `dangke` sentence.
- Remind neighbours about the drain with `Jang buang sampa di got`.
- Review a text that only adds `beta` and `dong` to Indonesian.
- Turn away a bahasa tanah or Hitu request.
- Stop a request for baileo ritual wording.

## Register And Semantics

- `ose` and `ale` are both you. Use the one that appears in the chosen dictionary sentence.
- `katong` covers we in the dictionary examples. Do not invent an exclusive twin.
- `pung` follows the possessor: `beta pung bapa`.
- `su` marks already inside attested lines. Do not add it to every verb.
- Code-mixing with Indonesian nouns is normal in the dictionary. Describe it. Do not purge it.

## Review Checklist

- Is the request Melayu Ambon rather than bahasa tanah or Hitu?
- Is every Melayu Ambon sentence copied from the dictionary examples in this skill or from a user sample?
- Did the output invent a `baku-` verb?
- Are `ose` and `ale` used inside sentences where the source uses them?
- Are prices, times, and places still clear in Indonesian when they were not in the source line?
- Does an adat answer refuse to script a baileo event?

## Output Patterns

- Direct request: the message first.
- Review request: name the glued-on particles, then a dictionary line plus Indonesian.
- Public text: prefer a dictionary sentence that already has the warning.
