# Sources

Language: Bahasa Melayu Ambon (Ambonese Malay)

Region/context: Kota Ambon and Maluku as a lingua franca. Indigenous bahasa tanah of Ambon and Lease is excluded.

## Source Confidence

Level 2. Balai Bahasa Provinsi Maluku published a bilingual dictionary with example sentences, and van Minde 1997 is a full grammar. This skill uses only the short examples read from those public pages.

## Editorial Position

Melayu Ambon is a Malay contact variety. Bahasa tanah is the local name, in that thesis, for the indigenous languages that remained in many Muslim villages after Malay became the city language. Peta Bahasa lists the indigenous cluster as Hitu. This skill writes only Melayu Ambon, and only in lines the dictionary or the pronoun source actually gives.
