# Sources

Language: Simalungun

Region/context: Sumatera Utara. Peta Bahasa lists dialek Simalungun inside Bahasa Batak, in Kabupaten Simalungun and Kabupaten Tanjung Balai, at 69,25 percent difference from dialek Toba. Glottolog lists a separate language. The working dictionary is Simalungun–Indonesia, not Toba.

## Source Confidence

Level 2. Kamus Bahasa Simalungun–Indonesia, edisi kedua, Balai Bahasa Provinsi Sumatera Utara, was read from the ministry PDF. Glosses in this skill come from that file. A community site that collects uppasa is not used for wording.

## Editorial Position

Ordinary chat may use `horas` because this dictionary defines it as the selamat said when people meet, with the example `haganup hanami makkatahon horas`. That is a Simalungun entry. It is not borrowed from the Toba skill. Mauliate was not found in the PDF that was read. Lemmas tagged Tb, including `jabu` for rumah, are not ordinary Simalungun wording. Adat verse and aksara Simalungun stay with a speaker. The dictionary names the script in passing (`surat sapuluh siah`) and this skill does not write it.
