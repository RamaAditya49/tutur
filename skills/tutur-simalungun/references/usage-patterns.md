# Usage Patterns

## Ordinary Output

A usable Simalungun-aware message is short. Open with `horas` when people are meeting, ask one printed question if it fits, and put the plan in Indonesian. If the user wants a full translation, quote only the sentences in the mirror and say the rest is not in the file.

## Sample Tasks

- Greet a cousin and ask where they are going, using `laho huja ho?`
- Tell a group the job is finished, using `domma sahei haganupan`, then the Indonesian detail.
- Compliment a house with `rumah ai handalan tumang`. Do not change rumah to jabu.
- Review a text that adds mauliate and calls itself Simalungun.
- Separate a Tb-tagged lemma from an untagged one.

## Review Checklist

- Is every Simalungun word inside a line in `local-mirror.md`, or in a sample the user supplied?
- If `horas` is used, is it the dictionary selamat, without mauliate attached?
- Are Tb-tagged words, including `jabu`, absent from ordinary lines?
- Were `ho` and `ham` kept in their own examples?
- Were `ahu` and `au` kept in their own examples?
- Is mixed text labeled mixed?
- Are Karo `mejuah-juah` and Pakpak `njuah-njuah` absent?
- Are names, dates, prices, and instructions unchanged?
- Is adat verse and aksara absent unless the user pasted it?

## Output Patterns

- Direct request: message first, source note second.
- Review request: name the Toba-only words, then a shorter rewrite.
- Public request: Indonesian carries the instruction. Simalungun stays the greeting or one printed sentence.
