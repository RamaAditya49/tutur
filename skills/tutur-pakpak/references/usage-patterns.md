# Usage Patterns

## Ordinary Output

A usable Pakpak-aware message is short. Open with `njuah-njuah` when a greeting is wanted, then say the practical part in Indonesian. Use a full Pakpak sentence only when the situation matches one printed in the 2023 book, such as a broken bridge or a child climbing a durian tree.

## Sample Tasks

- Greet a cousin in Sidikalang and say the package already arrived. The arrival detail stays Indonesian.
- Tell a group `njuah-njuah mo kita karinana`, then the meeting time in Indonesian.
- Warn a child about the durian tree with the printed sentence.
- Tell neighbors the bridge is already broken, using `enggo nceda jembaten, oda boi ke karap i`, if that is the fact.
- Review a text that opens with mejuah-juah or horas and calls itself Pakpak.

## Review Checklist

- Is every Pakpak word inside a line in `local-mirror.md`, or in a sample the user supplied?
- Is the greeting `njuah-njuah`, not `mejuah-juah` and not horas?
- Was `tulan` kept as tulang when it comes from that phonology example?
- Were `mela` and `mella` left distinct?
- Were nasals kept on the words that have them?
- Is the suak named when the user named a town?
- Is mixed text labeled mixed?
- Are names, dates, prices, and instructions unchanged?
- Is ritual language absent unless the user pasted it?
- Was the 1977 dictionary left unquoted, since its pages were not read?

## Output Patterns

- Direct request: message first, source note second.
- Review request: name the Karo or Toba words, then a shorter rewrite.
- Public request: Indonesian carries the instruction. Pakpak stays the greeting or one matching sentence.
