# Tutur Dayak Ngaju

## Overview

Use this skill for Bahasa Ngaju, the language Peta Bahasa lists as Dayak Ngaju, with many village dialects across Kapuas, Pulang Pisau, Gunung Mas, Katingan, Barito Selatan, and Kota Palangka Raya. ISO 639-3 `nij`, Glottocode `ngaj1237`. Glottolog also lists older names such as Kapuas, Kahayan, and Biadju. Those names are not a license to answer every "bahasa Dayak" request with this folder.

The 2013 Balai Bahasa dictionary already mixes Indonesian into Ngaju examples, including tarima kasih. Quote those examples. Do not invent the next sentence. Ritual and healing formulas are not written.

## Search And Discovery

Relevant searches: Bahasa Ngaju, Dayak Ngaju, kamus Dayak Ngaju, kamus Bahasa Ngaju, contoh Bahasa Ngaju, belajar Bahasa Ngaju, terjemahan Indonesia Ngaju, translate Bahasa Ngaju, Kahayan, Kapuas, Palangka Raya, ngaju hulu, AI skill Bahasa Ngaju.

Use this skill for source-aware Ngaju generation and review. It is not a certified translator. Dialect, adat, public, legal, educational, or official text stays with an Ngaju speaker when the line is not in the local sources.

## Human Voice

Di Palangka Raya, terima kasih yang tercetak di kamus Balai Bahasa ya tarima kasih, lalu alasan bantuannya menyusul. Arah masih dihitung dari sungai: ngaju artinya agak ke hulu, bukan nama semua suku Dayak. Minta tolong yang ada contohnya pendek saja: dohop ikei. Jangan tulis "bahasa Dayak" seolah bahasa Dayak yang lain ikut tertutup folder ini. Kalimat yang belum ada contohnya dibiarkan bahasa Indonesia.

## Workflow

1. Identify the task.
   - Translation needs a printed Ngaju example.
   - Style requests keep the Indonesian meaning and add only attested Ngaju.
   - If the user says Dayak without saying Ngaju, stop and ask. This skill does not cover other Dayak languages.

2. Check source confidence.
   - Read `references/sources.md` first.
   - Prefer Kamus Dwibahasa Dayak Ngaju–Indonesia, Balai Bahasa Provinsi Kalimantan Tengah, 2013.
   - Peta Bahasa lists dozens of village dialects. Do not present one desa as the only Ngaju.
   - A personal blog conversation list is support only.

3. Compose with source discipline.
   - Keep names, places, titles, dates, and facts unchanged.
   - Use verified Ngaju words only.
   - If the sentence is not attested, write Indonesian and label the result mixed.

4. Final pass.
   - Say the line is Ngaju, not "bahasa Dayak" in general.
   - Do not claim native-speaker or official authority.
   - Do not write a ritual or healing formula.

## Output Style

- For a direct request, give the message first.
- For a review, name the risk, then give a safer rewrite.
- For public, adat, legal, school, or government text, ask for an Ngaju speaker from the target dialect area.
- Label mixed Ngaju-Indonesian text as mixed.
