# Local Mirror

## Source Mirror

- Language: Bahasa Ngaju. Peta Bahasa headword: Dayak Ngaju. Glottolog: Ngaju.
- ISO 639-3: `nij`. Glottocode: `ngaj1237`.
- Glottolog status note: wider communication. The comment says it was widely used in Central Kalimantan in trade, church, and education.
- Alternate names on that entry include Kapuas, Kahayan, Biadju, Ngadju, and Dayak. This skill uses Ngaju only.
- Region: the Peta Bahasa dialect list runs through Kapuas, Pulang Pisau, Gunung Mas, Katingan, Barito Selatan, and Palangka Raya. Named samples include Kasongan, Kuala Kurun, Tewah, Pulang Pisau, Tangkiling, and Kalampangan.
- Source confidence: Level 2. Kamus Dwibahasa Dayak Ngaju–Indonesia, 2013, Balai Bahasa Provinsi Kalimantan Tengah. Examples below are from that book. The dash in a dictionary example stands for the headword. It is filled back in here and marked.
- A 1999 ungkapan dictionary exists and is not quoted.
- Source links are in `sources.md`. This file does not copy the dictionary.

## Local Usability

Use this file offline. Ordinary chat may quote one printed line and then switch to Indonesian. The 2013 book is a school-facing dictionary, so its examples are ordinary sentences, not a ritual corpus.

Peta Bahasa treats Dayak Ngaju as one language with many dialects. Another Dayak language on another Peta Bahasa page is out of scope even if the user calls both Dayak.

## Vocabulary And Semantics

Verified items only. Glosses follow the 2013 dictionary. Headwords restored from the entry dash are marked.

- dohop: v bantu. Example: "dohop ikei", glossed "bantu kami".
- pandohop: n pertolongan, bantuan. The printed example is "tarima kasih tagal ketun handiai", glossed "terima kasih atas pertolongan kalian kepada kami". The Indonesian words tarima kasih are inside that Ngaju line. Do not insert extra words into it.
- paisek: n pertanyaan. Example, headword restored: "narai paiseke dengam?", glossed "apa pertanyaannya padamu?"
- maandui: v mandi. Example: "ikei maandui hung sungei", glossed "kami mandi di sungai". The entry also writes the verb as mandui in the cross-reference.
- hapahari: bersaudara, from the ha- prefix list (hapahari = bersaudara) and the number example "ikei lime hapahari", glossed "kami lima bersaudara". Do not split this into a new address term.
- lewu: n kampung; desa. Example: "bapa harun dumah bara lewu", glossed "ayah baru datang dari kampung".
- ngaju: n di bagian agak ke hulu (tentang sungai). Separate entry Ngaju: nama salah satu subetnik Dayak di Kalimantan Tengah. Do not mix the place sense and the ethnic name.
- mandoa: v mendoakan. Example, headword restored: "aku mandoa ketun salamat sampai lewu", glossed "saya mendoakan kalian selamat sampai kampung". This is a travel wish in the dictionary, not a ritual script to extend.
- baise: v berhitung. Example, headword restored: "has baajar baise", glossed "ayo belajar berhitung".

Do not add ritual formulas, healing speeches, or kinship titles. hapahari stays inside the number example above.

## Generation Rules

1. Write the meaning in plain Indonesian first.
2. Add only Ngaju pieces listed above or supplied by the user with a source.
3. If a full sentence is not in the dictionary example, keep it in Indonesian and label the message mixed.
4. Say the dialect village is unspecified unless the user names it.
5. Do not answer a non-Ngaju Dayak request with these lines.
6. Do not "correct" tarima kasih out of the printed thanks example.
7. For public or professional text, keep time, place, price, and policy in Indonesian.
