# Sources

Language: Ngaju (Dayak Ngaju)

Region/context: Kalimantan Tengah. Peta Bahasa maps many village dialects along the Kapuas, Kahayan, Katingan, and nearby rivers, including Palangka Raya. Not a cover term for every Dayak language.

ISO 639-3: nij

Glottocode: ngaj1237

## Source Confidence

Level 2: a real dictionary exists. Balai Bahasa Provinsi Kalimantan Tengah published Kamus Dwibahasa Dayak Ngaju–Indonesia, edisi pertama, 2013, ISBN 978-602-7664-31-9, tim Anthony Suryanyahu dan kawan-kawan, penanggung jawab Sumadi. Worked sentences in this skill are example lines from that book. A 2019 second edition is catalogued and was not the file read here.

## Editorial Position

Quote dictionary examples whole. The book itself uses tarima kasih inside an Ngaju example, so that mix is attested, not a mistake to "purify". ngaju in the dictionary is a place word, "di bagian agak ke hulu" about a river, and also the ethnic name in a separate entry. Do not answer a generic Dayak request with these lines. Do not generate ritual or healing formulas. Do not treat Kasongan, Kuala Kurun, Tewah, Pulang Pisau, and Palangka Raya as one village dialect.
