# Examples

## Target-Language Examples

- Indonesian: "Apa kabar, Sahabat?"
  Bahasa Sumbawa: "Apa rungan, Kanti?"
  Meaning/note: Printed with that gloss in Ifansyah and Aini's Sumbawa Besar student transcript. Kamus Samawa-Indonesia glosses rungan as 'kabar' and gives an apa rungan example as 'apa kabar kampung halamanmu'.
  Usage: Casual kabar line to someone addressed as sahabat. Dialek Sumbawa Besar in that paper.
- Indonesian: "Di mana saya dapatkan buku itu?"
  Bahasa Sumbawa: "Me pang kaji dapat buku nan?"
  Meaning/note: Same transcript, with the Indonesian gloss printed beside it. kaji is the respectful 'saya'.
  Usage: Quote this question. Do not swap the object and keep the Samawa frame.
- Indonesian: "Anda berikan ke saya saja."
  Bahasa Sumbawa: "Sia beang ko saya mo."
  Meaning/note: Same transcript. sia is 'anda' for an older or higher addressee. saya inside the line is the paper's own mix.
  Usage: Only when the addressee matches sia. Mark a longer reply mixed if Indonesian follows.
- Indonesian: "Anda yang punya ini?"
  Bahasa Sumbawa: "Diri nan baeng deta ke?"
  Meaning/note: Same transcript. diri nan is 'anda' for a peer.
  Usage: Peer question about an object. Do not aim it at an elder.
- Indonesian: "Anda" (lebih hormat daripada sia).
  Bahasa Sumbawa: "kelam."
  Meaning/note: Bahastra honorific article, Sumbawa Besar informants. kelam is singular and higher than sia. sareasia or sia sarea is the plural.
  Usage: Name the pronoun. Do not build a new sentence around it.

## Casual Chat

Input:

> Balas teman sebaya di Sumbawa Besar yang lama tidak kelihatan.

Output (mixed):

> Apa rungan, Kanti? Baru kelihatan. Aku di rumah saja hari ini, jam 4 boleh mampir kalau sempat.

Note:

The first sentence is the attested transcript line. The rest is Indonesian, so the message is mixed. This is dialek Sumbawa Besar, not Bima and not Sasak.

## Public Reminder

Input:

> Ingatkan warga arisan besok malam.

Output (mixed):

> Apa rungan. Arisan lingkungan besok malam jam 20.00 di rumah ketua RT. Kabar lagi kalau tidak bisa datang.

Note:

Apa rungan is the kabar piece from the dictionary example and the transcript. The schedule stays in Indonesian. Mixed. Kanti is left off because this is not a note to one friend. For a loudspeaker or a printed notice, ask a Sumbawa Besar speaker.

## Professional Or Admin

Input:

> Pesan admin kampus: berkas beasiswa belum lengkap.

Output (mixed):

> Apa rungan. Berkas beasiswa belum lengkap. Mohon kirim ulang hari ini sebelum pukul 15.00. Nama dan NIM tetap di halaman pertama.

Note:

kaji and Pak Dekan appear in the campus transcript, but that line is about asking for a signature, not about this deadline. The deadline stays in Indonesian. Mixed. Sumbawa Besar.

## Adat Boundary

Input:

> Tulis sambutan tokal untuk nikahan keluarga.

Safe response:

> Kamus Samawa-Indonesia menggloss tokal sebagai undangan keluarga untuk membicarakan pernikahan. Sambutan tokal tidak disusun dari gloss itu. Minta teks yang sudah dipakai keluarga. Gelar dea, lalu, lala, atau daeng hanya dipakai kalau orangnya memang menyandang gelar itu.

## Review Mode

Input:

> Cek teks ini: "Tabeq, semeton. Apa rungan, matur tampiasih."

Response shape:

1. Flag Sasak pieces.
2. Keep the Samawa piece that is actually attested.
3. Ask for a speaker if the text will be printed.

Example review:

> Apa rungan ada di transkrip Sumbawa Besar sebagai apa kabar. Tabeq dan matur tampiasih adalah sapaan Sasak, bukan Samawa, dan semeton juga bukan dari sumber Samawa di skill ini. Untuk teman sebaya, pakai Apa rungan, Kanti? lalu lanjut bahasa Indonesia. Hasilnya mixed.
