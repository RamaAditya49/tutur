# Local Mirror

## Source Mirror

- Language: Bahasa Wolio. Also called Buton in some catalogs. The language of Baubau and Buton in this skill is Wolio, not every language spoken on Buton.
- ISO 639-3: `wlo`. Glottocode: `woli1241`. Glottolog status comment: threatened, 6b.
- Classification in Glottolog's Wolio entry and the Wikipedia summary: Austronesian, Wotu-Wolio. Not Bungku-Tolaki. Not Muna.
- Region, Peta Bahasa: Kota Baubau, Kabupaten Buton Selatan, Kabupaten Buton.
- Beside it, not instead of it: Muna in Baubau, Cia-Cia in Buton. Dialectometry about 81%–100% against both.
- Seven dialects: Waruruma (Kokalukuna), Liabuku (Bungi), Sorawolio (Kaisabu Baru), Wolio Keraton (Baadia, Murhum), Busoa (Batauga), Pasar Wajo, Kaimbulawa (Siompu). Differences about 51%–78%.
- Dictionary: Abas, Shaidy, and Jaya, Kamus Wolio-Indonesia, Pusat Pembinaan dan Pengembangan Bahasa, 1985.
- Preface facts used here: every Wolio word ends in a vowel; ordinary syntax is S-P or S-P-O; written tradition uses an Arabic-derived script speakers call aksara Wolio (Buri Wolio in later descriptions). Literary titles named there include Bulamaling, Indo Malussa, and Kaokabi. A fourth title is illegible in the text layer ("Kaluku xtnda"). Do not reconstruct it.

## Local Usability

This file is the offline substitute for the dictionary. It stores a handful of headwords whose glosses survived the interleaved PDF columns. It is not a copy of the dictionary.

Everyday messages may use those headwords. Keraton dialect, sara, sultanate letters, and Buri Wolio composition are review-only. A street chat in Baubau is not Wolio Keraton.

## Vocabulary And Semantics

From Kamus Wolio-Indonesia 1985, headword then gloss:

- `tabea`: salam; permisi; maaf. Example in the entry: `tabea kuloiopo`, glossed maaf, saya lewat dahulu. The PDF columns are interleaved. The headword gloss is the firm part. Use the example as that passing-by excuse, not as a new template.
- `tulungi`: tolong. Entry example pattern `a tulungi aku`, glossed dia menolong saya. `katulungi` is pertolongan. `potulu-tulungi` is saling tolong-menolong. Do not build a new benefactive sentence.
- `inda`: tidak. `inda pokia`: tidak mengapa. `inda daangia`: tidak ada. Use these pairs as wholes.
- `ingkita`: (1) kita, first person plural; (2) anda, second person, more respectful. Clean example: `yapai ta porope ingkita?` ke mana anda menuju? The other example on that line is too damaged by line breaks to reuse.
- `ingkoo`: engkau.
- `ingkomiu`: kamu sekalian. The dictionary example is a scolding line. Record the pronoun. Do not reuse the scolding sentence in a friendly message.
- `incia`: third person, visible throughout dictionary examples as dia. Do not invent a plural from this note. Later descriptions use a plural marker. This skill does not generate it without the dictionary line in front of the agent.

Speech habit from the preface, not from a phrase list: if a proposed Wolio word ends in a consonant, it is not Wolio spelling from this dictionary.

## Generation Rules

1. Write the meaning in plain Indonesian first.
2. Add only the Wolio pieces in the list above, or a user sample.
3. Open with `tabea` for a greeting, a permission, or a short apology.
4. Choose `ingkita` when the addressee is being respected, `ingkoo` for a plain engkau. Say which one was chosen.
5. Reject any new Wolio token that ends in a consonant.
6. Do not import Muna morphology or Tolaki `inggomiu`.
7. Mark mixed text as mixed.
8. If the user asks for Keraton, sara, a sultan's letter, or Buri Wolio, return Indonesian plus a review note.

## Starter Lexicon Policy

Add a Wolio word only from a readable dictionary example or a user sample. Do not paste dictionary pages. Do not repair broken OCR into a new word.

## Register Handling

- Everyday: `tabea`, `inda pokia`, `tulungi`, Indonesian for the rest.
- Respectful you: `ingkita`, with the attested question left intact if a destination question is needed.
- Public: Indonesian for time, place, and duty.
- Professional: Indonesian for documents, money, and deadlines.
- Keraton/sara: no composed formula. Baadia is a dialect location, not a style the agent may imitate.
