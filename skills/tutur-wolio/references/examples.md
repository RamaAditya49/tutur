# Examples

## Target-Language Examples

- Indonesian: "Salam; permisi; maaf."
  Bahasa Wolio: "tabea"
  Note: Kamus Wolio-Indonesia, Abas, Shaidy, and Jaya, 1985. Headword gloss. Example in the same entry: `tabea kuloiopo` "maaf, saya lewat dahulu". The PDF text layer interleaves columns, so the headword gloss is the firm part. https://repositori.kemendikdasmen.go.id/2958/1/kamus%20wolio%20indonesia%20%20%20%20%20205.pdf
  Usage: Greeting, permission, or a short apology. `tabea kuloiopo` only for the passing-by excuse.
- Indonesian: "Tolong." Example: "Dia menolong saya."
  Bahasa Wolio: "tulungi." Example pattern: "a tulungi aku."
  Note: Same dictionary. `katulungi` is pertolongan. `potulu-tulungi` is saling tolong-menolong.
  Usage: The verb, not a new sentence about a different favor.
- Indonesian: "Tidak mengapa." Also "tidak ada."
  Bahasa Wolio: "inda pokia." "inda daangia."
  Note: Same dictionary. `inda` is tidak. Use the pairs as wholes.
  Usage: `inda pokia` when the meaning is really tidak mengapa.
- Indonesian: "Ke mana anda menuju?"
  Bahasa Wolio: "yapai ta porope ingkita?"
  Note: Same dictionary. `ingkita` is kita, and also anda in the more respectful sense. `ingkoo` is engkau. `ingkomiu` is kamu sekalian.
  Usage: This question to one person being respected. Do not reuse the dictionary's scolding example for `ingkomiu`.

## Casual Chat

Input:

> Balas saudara di Baubau yang bertanya sudah lewat di depan rumah belum.

Output (mixed):

> Tabea kuloiopo. Sudah lewat tadi. Aku singgah besok pagi, ya.

Note:

`Tabea kuloiopo` is the dictionary excuse "maaf, saya lewat dahulu". The plan for tomorrow is Indonesian. Not Muna. Not Keraton.

## Public Reminder

Input:

> Ingatkan warga lingkungan soal kerja bakti.

Output (mixed):

> Tabea. Besok kerja bakti jam 07.00. Bawa alat kebersihan. Inda pokia kalau terlambat sedikit, asal kabari ketua RT sebelum jam 06.30.

Note:

`tabea` and `inda pokia` are attested. The hour and the tool stay Indonesian. This is everyday Wolio-aware Indonesian, not dialek Wolio Keraton.

## Professional Or Admin

Input:

> Admin penginapan di Baubau meminta foto KTP.

Output (mixed):

> Tabea. Foto KTP belum masuk. Mohon kirim sebelum pukul 16.00. Data hanya untuk administrasi penginapan.

Note:

Room rules and the deadline stay Indonesian. `ingkita` is available if the guest is addressed respectfully in a Wolio question, but this note does not need that question.

## Adat Boundary

Input:

> Buat sambutan sara keraton Baadia untuk tamu dinas.

Output:

> Dialek Wolio Keraton tercatat di Kelurahan Baadia, Kecamatan Murhum. Kamus 1985 menyebut tradisi tulis kesultanan dan judul-judul yang sudah ada. Skill ini tidak menyusun kalimat sara atau surat sultan. Sambutan tamu dinas yang aman: `Tabea.` Lalu nama tamu, jam, dan tempat dalam bahasa Indonesia. Kalau panitia punya teks keraton, tempelkan teks itu, jangan dilengkapi.

## Review Mode

Input:

> Cek: "Tabea muna, ingkomiu semua wajib hadir di keraton pakai bahasa Wolio penuh."

Response:

1. `tabea` is Wolio for salam, permisi, maaf. The word `muna` is the name of a different language. Do not attach it.
2. `ingkomiu` means kamu sekalian. The dictionary example that uses it is a scolding line. It does not mean "everyone must attend".
3. A keraton order is outside the everyday glosses.

Safer rewrite (mixed):

> Tabea. Undangan acara besok dikirim panitia. Jam dan tempat menyusul dalam bahasa Indonesia. Teks keraton, kalau ada, dari pihak Baadia, bukan dari skill ini.
