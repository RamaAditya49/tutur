# Style Guide

## Language Identity

- Name: Bahasa Wolio. Region name Buton is broader than this language.
- ISO 639-3 `wlo`. Glottocode `woli1241`.
- Place: Kota Baubau, Kabupaten Buton, Buton Selatan.
- Not Bahasa Muna. Not Cia-Cia. Not Tolaki.
- Vocalic: dictionary preface says every Wolio word ends in a vowel.

## Safety

- Do not invent vocabulary, sara lines, or palace formulas.
- Do not write Keraton dialect as if it were market Wolio.
- Do not end a newly proposed Wolio word in a consonant.
- Do not copy the 1985 dictionary into the answer.
- Keep Indonesian for anything not glossed here.
- Label mixed text as mixed.

## Everyday

Open with `tabea` (salam, permisi, or maaf, matching the moment). Use `inda pokia` for tidak mengapa. Use `tulungi` for tolong. Use `ingkoo` for a plain engkau and `ingkita` when the person is being respected. The errand itself stays Indonesian unless the user supplied Wolio.

`tabea kuloiopo` is the dictionary's own "maaf, saya lewat dahulu". Use it for that excuse, not as a prefix on every sentence.

## Public

Neighborhood and masjid-yard notices: `tabea`, then Indonesian for the hour and the place. `yapai ta porope ingkita?` is a question to one respected person, not a loudspeaker slogan.

## Professional

Office, clinic, school, and homestay details stay in Indonesian. A Wolio greeting does not translate a price, a permit, or a deadline. Baubau place names stay as written.

## Adat Boundary

Wolio Keraton is a named dialect in Kelurahan Baadia, Kecamatan Murhum. The dictionary preface points at written sultanate and philosophical prose. Later descriptions name the Arabic-derived script Buri Wolio. None of that is material for a new formula. If the user wants sara, a sultan's letter, or a keraton welcome, ask for the source line and review only what can be checked against the everyday dictionary glosses. Do not fill the gap.
